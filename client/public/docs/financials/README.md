# Financial document drop folder

Approved public filings belong here. The Financials page reads availability from `client/src/data/financial-documents.ts`. A `null` `href` renders a coming-soon state and never a broken link.

| Document | Drop this file | Then set `href` to |
| --- | --- | --- |
| 2025 Form 990 (PDF) | `2025-form-990.pdf` | `/docs/financials/2025-form-990.pdf` |
| 2025 financial statements (convert Word to PDF) | `2025-financial-statements.pdf` | `/docs/financials/2025-financial-statements.pdf` |

Do not commit draft, unaudited, or unapproved financial files. Candy approves public financial documents before they are posted.
